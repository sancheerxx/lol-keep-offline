# LOL 保持离线 (LoL Keep Offline)

一个用于《英雄联盟》客户端的本地小工具：**让好友看到的你始终是「离线」**，即使你正在排队、选英雄或已经进入对局。

通过客户端自带的本地接口（LCU API）把显示状态锁成离线，并持续压制客户端在每个阶段切换时重新推送的「队列中 / 英雄选择 / 游戏中」字样。

> ⚠️ 非官方工具。使用前请阅读文末的「限制与风险」。

---

## 功能

- **锁定离线**：好友列表里显示灰点，看不到你在线。
- **擦除对局文字**：把 `gameStatus` 压回 `outOfGame`，好友不再看到「队列中 / 选人中 / 游戏中 / 正在创建房间」。
- **实时抢占**：WebSocket 事件驱动 + 0.2 秒轮询双保险，客户端一改就抢回来。
- **客户端启动即自动开始**：勾选后，检测到客户端登录就自动进入保持状态。
- **开机自动启动**：可选，写当前用户的开机启动项（`HKCU\...\Run`）。
- **图形界面**：深色单窗口，选状态 → 点开始 → 看实时日志。
- 状态支持：`离线`、`在线`、`离开`。

## 快速开始

### 方式一：下载打包好的 exe（推荐）

到 [Releases](../../releases) 页面下载 `LolKeepOffline.exe`，双击运行即可，无需安装 Python。

- 首次启动需要解压约 2–3 秒；
- 若被安全软件拦截或双击无反应，可用免解压版（文件夹形式，启动更快）。

### 方式二：从源码运行

```powershell
pip install aiohttp psutil
python lol_keep_offline_gui.py
```

### 使用步骤

1. 打开英雄联盟客户端并登录（工具会在客户端就绪后自动连接）。
2. 选择要维持的状态，默认「离线」。
3. 点击「开始保持」；若勾选了自动开始，则无需点击。
4. 让不在你队伍里的好友（或手机端小号）查看你的状态，应为灰点、无对局文字。

命令行版本（无界面，适合做开机脚本）：

```powershell
python keep_offline_ws_fixed.py 5   # 5=离线 1=在线 2=离开
```

## 工作原理

1. 从 `LeagueClientUx.exe` 的命令行参数读取 `--app-port` 与 `--remoting-auth-token`；
2. 用 Basic Auth 调用本地 HTTPS 接口 `PUT /lol-chat/v1/me`：

   ```json
   { "availability": "offline",
     "lol": { "gameStatus": "outOfGame", "gameMode": "", "gameQueueType": "" } }
   ```

3. 连接 `wss://127.0.0.1:<port>/` 订阅 `OnJsonApiEvent_lol-chat_v1_me` 与
   `OnJsonApiEvent_lol-gameflow_v1_gameflow-phase`，事件到达时立刻纠偏；
4. 另有 0.2 秒（空闲时 1 秒）轮询兜底，防止事件丢失导致状态被改回而不自知。

> WebSocket 需要使用独立的连接/会话；与 HTTP 请求共用同一连接池时，国服客户端会返回 404。

## 限制与风险

- **这不是真正的断网**：你仍然正常排队、对局、下载更新；只是对外显示为离线。
- **竞速残留**：客户端在阶段切换时会重新推送状态，本工具只能在其后尽快覆盖，好友侧可能看到极短的闪烁。
- **同队可见**：和你处于同一房间/队伍的玩家仍能看到队伍状态，这部分不经由 `lol-chat/me`。
- **随版本变化**：LCU 是未公开接口，客户端更新后行为可能改变；若某版本拒绝改写 `lol`，工具会自动退化为「只维持离线」。
- **账号风险**：仅调用本地接口、不读写内存、不修改游戏文件，但仍属第三方工具，请自行判断使用风险；请勿用于对局内自动操作等违规用途。

## 常见问题

**双击后没有任何反应？**
用「免解压版」文件夹里的 exe；或者以管理员身份运行（当客户端以管理员启动时，读取进程命令行需要相同权限）。

**一直显示「等待客户端启动…」？**
确认客户端已登录进大厅。工具通过 `LeagueClientUx.exe` 的命令行读取端口和令牌，客户端未运行或权限不足时读不到。

**日志出现「实时监听中断，改用轮询维持」？**
WebSocket 握手失败（常见于国服），此时仍由 0.2 秒轮询维持状态，功能不受影响。

**好友看到「游戏中」一闪而过？**
说明当前客户端推送频率高于抢占间隔，属于预期内的竞速残留。
